## 4. 子计划 A — Android 真机/模拟器逐项 GUI 取证

**前置：** 起模拟器 `pskora_api35`（API 35）或接真机 + `adb devices` 就绪；打非生产 Debug APK（勿覆盖线上 1.24/25）；本地或只读线上 API。
**步骤（每项一截图，操作前后对比）：**
1. 登录（脱敏，密码字段打码）→ 收件箱列表。
2. 文件选择器 / 照片选择器上传 → 200 响应。
3. 收件确认对话框（目标设备/同步网页/发送）→ 发送成功 + curl 只读复核 `/api/transfers` 出现 delivered。
4. 下拉刷新 / 下载 → 打开已接收文件（系统查看器）/ 转存核验。
5. 网盘：搜索、类型筛选、续期、图钉、删除、去重（同内容置顶）、重名文件处理。
6. 下载状态在重启后恢复对账。
7. 系统分享面板含 AnyCopy → 分享确认。
8. 通知触达（本地实例发文本经 SSE → Android 通知）。
**风险：** 低（不签名、不发布）。敏感节点截图排除入库。
**放行点 A：** Zane go → 起模拟器执行。

## 5. 子计划 B — Mac 真机 GUI（OS 集成 + 应用内操作）

**前置：** 用**非生产** Flutter 构建（Debug 窗口 pos/size 已知），或隔离位置的候选包；**绝不启动生产 `/Applications/CopySync.app` 做破坏性操作**；Accessibility + Screen Recording 已授权（本机已具备）。
**步骤：**
1. 菜单栏全项、快捷键（⌘, / ⌘. / ⌘J）、状态栏 ✓。
2. 区域截图交互框选（⌘J）→ 截图入历史。
3. 真实复制 → 历史「最近复制」逐行 → 粘贴到前一应用；忽略下一次复制；历史悬浮固定。
4. 应用内按钮：改名、图钉、续期、下载、删除、彻底清空、去重（SHA-256 置顶）。
5. 权限请求（粘贴权限/屏幕录制）、登录时启动、Finder 定位接收文件夹、清理历史缓存。
6. 在线状态心跳「N 台设备在线」。
**风险：** 中（cliclick 会改动演示数据）——用一次性演示数据集，操作后不要求恢复但需在非生产实例上。
**放行点 B：** Zane go → 本机非生产构建执行。

## 6. 子计划 C — 更新安装 / 签名 / 回滚（最高风险）

**前置：** 隔离副本上操作；不动 `updates/CopySync-Mac-latest.zip` 与 `build-2.0/` 原件。
**步骤（每步单独放行）：**
1. Mac：检查更新 → 下载 → 校验 → 安装到**隔离位置** → 启动验证 → **回滚**到前版本验证可用。
2. Android：`update.check/download/install`，SHA-256 校验（对照 23690875…04d890 等），安装非生产 APK → 回滚。
**风险：** 高——改动可分发产物、可能影响后续发布。**每一步都需 Zane 单独 go/no-go，且在隔离环境。**
**放行点 C：** 逐步放行，默认 no-go。
